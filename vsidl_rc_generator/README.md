# Runtime Configuration generator tool

The purpose of this tool is to generate runtime configuration files that are needed by SDV agents that use VSIDL provider library (`libsdv_config_provider`).
The runtime configuration consists of:

*   Schemas of Protobuf messages used in the catalog
*   SOME/IP mapping files
*   Diagnostic declarations

This tool can also be used to generate build files (`Android.bp`) that specifies `prebuilt` modules, to make it easier to include the generated runtime configuration files.

## Flags

*   `catalog_path`: path to the VSIDL catalog
*   `output_path`: path to folder where output should be generated
*   `dependency_catalog_path`: Optional. Specifies the directories of the dependent protos outside of the `catalog_path`. Each directory must contain an `Android.bp` file with a `rust_protobuf` build target to generate Rust API for the dependent protos. In the case of multi-layered dependency graph, please pass in one list with all the directories in the graph.
*   `variant`: Optional. Defaults to `RuntimeConfig`. Specifies the mode in which the runtime config generator should run. `RuntimeConfig` generates runtime config files for SOME/IP and Diagnostics. `RuntimeConfigPrebuilts` generates build file(s) containing `prebuilt` modules that can be used to include the file(s) generated by `RuntimeConfig` variant in other modules or in the VM image itself.
*   `package_name`: Optional argument specifying package of the service bundle for which to run the generator
*   `service_bundle_name`: Optional argument specifying name of the service bundle for which to run the generator.

## Usage

### Build

```bash
m vsidl_rc_generator
```

### Run config generator for `prebuilt_etc` / `genrule` build targets generation for catalog

Note: most of the flags correspond to `vsidlc` flags:

```bash
vsidl_rc_generator --catalog-path $(path_to_catalog) --output-path $(path_to_output_bp_file) --dependency-catalog-path $(path_to_dependency_catalog) --filegroup $(name_of_filegroup_with_all_catalog_files) --variant runtime-config-prebuilts
```

This will generate all needed build targets for the catalog.
**See generated comments on those targets to see instructions on how the targets are expected to be used (with relation to Service Bundle manifest).**

Generated targets will leverage the following modes of `vsidl_rc_generator`:

#### Run runtime config generator for whole catalog

```bash
vsidl_rc_generator --catalog-path $(path_to_catalog) --output-path $(output_path) --dependency-catalog-path $(path_to_dependency_catalog)
```

This command produces 2 files: `vsidl-config.binpb` and `someip-config.binpb` that contain proto schemas and SOME/IP mappings for the *whole catalog* respectively.

#### Run runtime config generator for sepcific bundle

```bash
vsidl_rc_generator --catalog-path $(path_to_catalog) --output-path $(output_path) --dependency-catalog-path $(path_to_dependency_catalog) --package_name $(bundle_package) --service_bundle_name $(bundle_name)
```

This command produces 2 files: `vsidl-config.binpb` and `diagnostics-config.binpb` that contain proto schemas and Diagnostic declarations for the *specific service bundle* respectively.
