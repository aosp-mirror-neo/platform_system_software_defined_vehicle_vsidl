# **E401**: SdvPublication annotation must include an even `message_count` >= 2

## Description

`message_count` defines the length of the message queue. The queue must be able
to hold at least 2 messages and must have an even length.

## Rationale (Why is this bad?)

**Dead Code**: If the queue length was set to zero, subscribers would not be
able to receive messages.

## Error Example

```textproto
message BatteryLevel {
  option (sdv.vsidl.v1.publication) = {
    channels_enum: "sdv.test.BatteryChannels"
    message_count: 0
    model: SINGLE_PUB
  };
  uint32 level = 1;
}
```

## How to Fix

Increase the `message_count`.

```textproto
message BatteryLevel {
  option (sdv.vsidl.v1.publication) = {
    channels_enum: "sdv.test.BatteryChannels"
+   message_count: 8
    model: SINGLE_PUB
  };
  uint32 level = 1;
}
```
