# **E511**: Certain fields in proto messages require annotations

## Description

A message in a pubsub service contains the one of the following datatypes
without annotation.

**repeated_field_max_count annotation**

-   any datatypes with repeated field type

**variable_type_max_size annotation**

-   string
-   bytes
-   google.protobuf.Any
-   google.protobuf.Api
-   google.protobuf.BytesValue
-   google.protobuf.Enum
-   google.protobuf.EnumValue
-   google.protobuf.Field
-   google.protobuf.FieldMask
-   google.protobuf.Method
-   google.protobuf.Mixin
-   google.protobuf.Option
-   google.protobuf.SourceContext
-   google.protobuf.StringValue
-   google.protobuf.Struct
-   google.protobuf.Type
-   google.protobuf.Value
-   google.protobuf.ListValue

## Rationale (Why is this bad?)

The datatypes above do not have a fixed size.

We need the size information from annotation to calculate the message size.

## Error Example

```textproto
message SampleMessage {
  google.protobuf.Value protobuf_value = 1;
  repeated int32 repeated_int= 2;
  repeated string repeated_string = 3;
}
```

## How to Fix

Add annotation to all the datatypes that require annotation.

```textproto
message SampleMessage {
  google.protobuf.Value protobuf_value = 1 [(.sdv.vsidl.v1.variable_type_max_size) = 6];
  repeated int32 repeated_int = 2 [(.sdv.vsidl.v1.repeated_field_max_count) = 5];
  repeated string repeated_string = 3 [(sdv.vsidl.v1.repeated_field_max_count) = 5, (sdv.vsidl.v1.variable_type_max_size) = 20];
}
```
