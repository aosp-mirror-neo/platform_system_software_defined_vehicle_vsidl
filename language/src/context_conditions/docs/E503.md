# **E503**: Having an RPC client requires having an RPC server with the requested service

## Description

RPC clients require that there is at least one RPC server serving the requested
service

## Rationale (Why is this bad?)

Unintended Behavior: If there is no RPC server for an RPC client, the client’s
requests would never get answered.

## Error Example

```textproto
sdv_service_bundle {
  name: "SeatHeatingController"
  client {
    service: "SetHeatingLevel"
  }
}
```

## How to Fix

**Alternative 1**: Add a server that serves the service requested by the client.

```textproto
sdv_service_bundle {
  name: "SeatHeatingController"
+ server {
+   service: "SetHeatingLevel"
+ }
  client {
    service: "SetHeatingLevel"
  }
}
```

**Alternative 2**: Remove the client.

```textproto
sdv_service_bundle {
  name: "SeatHeatingController"
- client {
-   service: "SetHeatingLevel"
- }
}
```
