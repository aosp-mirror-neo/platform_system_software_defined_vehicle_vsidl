# **E100**: Multiple RPC servers are defined for the same service in the same service bundle

## Description

This error occurs when a service bundle defines multiple RPC servers that handle
the same service. In other words, within a single service bundle, there are two
or more server definitions that are configured to respond to requests for the
same RPC service.

## Rationale (Why is this bad?)

**Undefined Behavior**: The system will randomly choose one of the servers at
runtime, leading to inconsistent results.

## Error Example

```textproto
sdv_service_bundle {
  name: "DuplicatedUnnamedServer"

  server {
    service: "sdv.test.PlaceholderRpc"
  }

  server {
    # Error: This service is already served by the server above
    service: "sdv.test.PlaceholderRpc"
  }
}
```

## How to Fix

Move the servers to different service bundles.

```textproto
sdv_service_bundle {
  name: "FirstServiceBundle"

  server {
    service: "sdv.test.PlaceholderRpc"
  }
}

sdv_service_bundle {
  name: "SecondServiceBundle"

  server {
    service: "sdv.test.PlaceholderRpc"
  }
}
```
