# **E10A**: Publication is unused

## Description

A publication is defined but is not used by any publisher.

## Rationale (Why is this bad?)

An unused publication is considered dead code. It can be misleading to
developers who might assume it is actively being used, and it adds unnecessary
clutter to the Protobuf definition, making the API harder to understand and
maintain.

## Error Example

```textproto
-------- PROTO --------
message TirePressure {
  option (sdv.vsidl.v1.publication) = {
    message_count: 8
    model: MULTI_PUB
  };
  uint32 pressure = 1;
}
-------- VSIDL --------
# Warning: No publisher is defined for the 'TirePressure' in any VSIDL files.
```

## How to Fix

**Alternative 1**: Remove the publication in proto file.

```textproto
-------- PROTO --------
message TirePressure {
- option (sdv.vsidl.v1.publication) = {
-   message_count: 8
-   model: MULTI_PUB
- };
  uint32 pressure = 1;
}
```

**Alternative 2**: Add publisher for this publication.

```textproto
-------- VSIDL --------
sdv_service_bundle {
  name: "PublishingBundle"

  publisher {
    type: "TirePressure"
  }
}
```
