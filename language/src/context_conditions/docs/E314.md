# **E314**: Topics must be globally unique across all publishers

## Description

This error occurs when multiple publishers use the same topic but publish
different Protobuf message types.

## Rationale (Why is this bad?)

**Communication Errors**: Topics identify unique communication paths for a
specific message type. If the same topic is used for different types,
subscribers might receive data they cannot decode, or data might be delivered to
the wrong services, leading to undefined behavior or system crashes.

## Error Example

```vsidl
service_bundle {
  name: "ServiceOne"
  publisher {
    message: "TypeA"
    topic: "my_topic"
  }
}

service_bundle {
  name: "ServiceTwo"
  publisher {
    message: "TypeB"
    # ERROR: Topic "my_topic" is already used for "TypeA"
    topic: "my_topic"
  }
}
```

## How to Fix

Ensure that each topic is unique for its associated message type. If different
types are intended to be sent over different topics, use unique names for each.

```vsidl
service_bundle {
  name: "ServiceOne"
  publisher {
    message: "TypeA"
    topic: "topic_a"
  }
}

service_bundle {
  name: "ServiceTwo"
  publisher {
    message: "TypeB"
    topic: "topic_b"
  }
}
```
