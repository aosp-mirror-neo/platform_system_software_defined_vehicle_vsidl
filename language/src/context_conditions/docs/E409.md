# E409: RPC channel is mandatory

## Description

All RPC servers and clients must explicitly specify an RPC channel.

## Rationale (Why is this bad?)

Without this field, clients cannot find servers.

## Examples

### Incorrect

```vsidl
service_bundle MyService {
    server {
        service: "MyService"
        // Missing channel
    }
}
```

### Correct

```vsidl
service_bundle MyService {
    server {
        service: "MyService"
        channel: "main"
    }
}
```
