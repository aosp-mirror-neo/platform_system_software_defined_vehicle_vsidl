# **E504**: Having a subscriber requires having a publisher with the requested type and channel

## Description

Subscribers require that there is at least one publisher serving the requested
type in the requested channel.

## Rationale (Why is this bad?)

**Unintended Behavior**: If there is no publisher for a subscriber, the
subscriber would never receive any messages.

## Error Example

```textproto
sdv_service_bundle {
  name: "TirePressureMonitor"
  subscriber {
    type: "TirePressure"
  }
}
```

## How to Fix

**Alternative 1**: Add a publisher that publishes the publication requested by
the subscriber (in the requested channel).

```textproto
sdv_service_bundle {
  name: "TirePressureMonitor"
+ publisher {
+   type: "TirePressure"
+ }
  subscriber {
    type: "TirePressure"
  }
}
```

**Alternative 2**: Remove the subscriber.

```textproto
sdv_service_bundle {
  name: "TirePressureMonitor"
- subscriber {
-   type: "TirePressure"
- }
}
```
