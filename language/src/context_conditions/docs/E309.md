# **E309**: Service bundles must have unique fully-qualified names

## Description

There may not be two service bundles with the same fully-qualified name.

## Rationale (Why is this bad?)

**Code Generation Errors**: The code generator determines the path of generated
code based on the fully-qualified name of the service bundle. For example, the
code for `this.is.an.ExampleBundle` will be generated into
`generated_rs/this/is/an/example_bundle/service_bundle.rs`. If multiple service
bundles had the same fully-qualified name, their files would overwrite each
other while generating code.

## Error Example

```textproto
package: "com.sdv.google.test"
sdv_service_bundle {
  name: "A"
}
-------------------------------
package: "com.sdv.google.test"
sdv_service_bundle {
  # ERROR: There's already a service bundle with FQN "com.sdv.google.test.A"
  name: "A"
}
```

## How to Fix

**Alternative 1**: Put one of the service bundles in a different package.

```textproto
package: "com.sdv.google.test"
sdv_service_bundle {
  name: "A"
}
-------------------------------
- package: "com.sdv.google.test"
+ package: "com.sdv.google.other"
sdv_service_bundle {
  name: "A"
}
```

**Alternative 2**: Rename one of the service bundles

```textproto
package: "com.sdv.google.test"
sdv_service_bundle {
  name: "A"
}
-------------------------------
package: "com.sdv.google.test"
sdv_service_bundle {
  - name: "A"
  + name: "B"
}
```
