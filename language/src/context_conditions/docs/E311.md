# **E311**: Subscriber channel redeclared in a service bundle

## Description

This error occurs when the same subscriber channel for a given type is declared
more than once within the same service bundle.

## Rationale (Why is this bad?)

Redeclaring the same subscriber channel leads to unnecessary code duplication.
Since multiple subscribers for the same channel can reuse a single function,
repeating the declaration is redundant.

## Error Example

The following examples show the `FRONT_LEFT` channel being declared more than
once in the same service bundle.

**Specifying the same channel in a single subscriber declaration**

```textproto
sdv_service_bundle {
  name: "SubscriberBundle"

  subscriber {
    type: "TirePressure"
    channel: "FRONT_LEFT"
    channel: "FRONT_LEFT"
  }
}
```

**Specifying the same channel in multiple subscriber declaration**

```textproto
sdv_service_bundle {
  name: "SubscriberBundle"

  subscriber {
    type: "TirePressure"
    channel: "FRONT_LEFT"
  }

  subscriber {
    type: "TirePressure"
    channel: "FRONT_LEFT"
  }
}
```

## How to Fix

Remove the duplicated subscriber channel declaration.

```textproto
sdv_service_bundle {
  name: "SubscriberBundle"

  subscriber {
    type: "TirePressure"
    channel: "FRONT_LEFT"
  }
}
```
