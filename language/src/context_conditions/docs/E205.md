# **E205**: User-defined `build_cfg` `target_name` must be in snake case. Not all chars are in \[a-z0-9`_`\]

## Description

VSIDL allows users to define a specific build target name for a given Service
Bundle. This user-defined string needs to be in the snake case.

## Rationale (Why is this bad?)

**Soong Requirement Violation**: Invalid snake case string can result in invalid
build target for Soong.

## Error Example

```textproto
sdv_service_bundle {
    name: "ServiceBundleTest3"
    build_cfg {
        target_name: "ServiceBundleTargetName"
    }
}
```

## How to Fix

Update the `build_cfg.target_name` string to be snake case

```textproto
sdv_service_bundle {
    name: "ServiceBundleTest3"
    build_cfg {
        target_name: "service_bundle_target_name"
    }
}
```
