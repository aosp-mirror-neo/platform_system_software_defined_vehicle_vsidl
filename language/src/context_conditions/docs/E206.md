# **E206**: User-defined `build_cfg` `target_name` must be in snake case. Contains consecutive underscores

## Description

VSIDL allows users to define a specific build target name for a given Service
Bundle. This user-defined string needs to be a valid snake case string. Valid
snake case strings do not contain multiple consecutive `_`.

## Rationale (Why is this bad?)

**Soong Requirement Violation**: Invalid snake case string can result in invalid
build target for Soong.

## Error Example

```textproto
sdv_service_bundle {
    name: "ServiceBundleTest1"
    build_cfg {
        target_name: "service_bundle_target__name"
    }
}
```

## How to Fix

Be sure the `target_name` does not contain consecutive `_` characters.

```textproto
sdv_service_bundle {
    name: "ServiceBundleTest1"
    build_cfg {
        target_name: "service_bundle_target_name"
    }
}
```
