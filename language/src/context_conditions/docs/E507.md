# **E507**: Android.bp `rust_protobuf` defaults

## Description

This error is triggered when the defaults attribute is used inside a
`rust_protobuf` target process by VSIDLC.

## Rationale (Why is this bad?)

VSIDLC does not parse defaults defined in all Android.bp files of Android
projects, therefore support for the defaults field is not supported.

## Error Example

```textproto
rust_defaults {
  name: "rust_default_lib",
  srcs: ["lib.rs"],
}

rust_protobuf {
  name: "defaults_name",
  crate_name: "defaults_crate",
  defaults: ["rust_default_lib"],
}
```

## How to Fix

Instead of importing default from another Android.bp defined target, all the
parameters need to be specified

```textproto
rust_protobuf {
  name: "defaults_name",
  crate_name: "defaults_crate",
  srcs: ["lib.rs"],
}
```
