# **E40E**: SOME/IP `topic` and `capacity` must be defined together.

## Description

This error occurs when a SOME/IP event mapping (`SimpleEvent` or `GroupEventPart`) defines either `topic` or `capacity`, but not both.

## Rationale (Why is this bad?)

**Incomplete Configuration**: In the latest VSIDL syntax, a topic-based mapping requires both the topic name and its corresponding publisher capacity. Providing only one makes the configuration ambiguous or non-functional for code generation.

## Error Example

```vsidl
someip_mapping {
    someip_service_mapping {
        someip_service_id: 0x1234
        instance {
            instance_id: 0x1000
            sdv_topic_parameterization {
                key: 0
                value {
                    // Error: topic is set but capacity is missing
                    topic: "my-topic"
                }
            }
        }
    }
}
```

## How to Fix

Ensure both `topic` and `capacity` are defined together.

```vsidl
someip_mapping {
    someip_service_mapping {
        someip_service_id: 0x1234
        instance {
            instance_id: 0x1000
            sdv_topic_parameterization {
                key: 0
                value {
                    topic: "my-topic"
                    capacity: 10
                }
            }
        }
    }
}
```
