# **E201**: User-defined service unit name’s first character is not lowercase letter

## Description

User-defined service unit names must start with a lowercase letter.

## Rationale (Why is this bad?)

**Comm Stack Requirement Violation**: The user-defined name is used as-is in
generated code, hence it must follow the name conventions for unit names
enforced by Comm Stack.

## Error Example

```textproto
server {
  service: "sdv.test.PlaceholderRpc"
  # Error: User-defined name does not start with [a-z]
  service_unit_name: "11-test"
}
```

## How to Fix

Change the user-defined name to start with a lowercase letter

```textproto
server {
  service: "sdv.test.PlaceholderRpc"
  service_unit_name: "a11-test"
}
```
