# **E60B**: RPC client uses a type that is implemented by more than one Proto RPC service

## Description

The RPC services an RPC client refers to must be unambiguously defined in
Protobuf.

## Rationale (Why is this bad?)

**Undefined Behavior**: If there are multiple implementations for the requested
RPC service in Protobuf, it would be ambiguous which one to choose.

## Error Example

```textproto
--------- PROTO ---------
// Request to set seat heating
message SetSeatHeatingRequest {
  enum Seat {
    DRIVER = 0;
    PASSENGER = 1;
  }
  Seat seat = 1;
  SeatHeatingLevel level = 2;
}

// Response to setting seat heating
message SetSeatHeatingResponse {
  bool success = 1;
}

// Seat heating service
service SeatHeatingService {
  rpc SetSeatHeating (SetSeatHeatingRequest) returns (SetSeatHeatingResponse);
}

// ERROR: This is already defined above
// Seat heating service
service SeatHeatingService {
  rpc SetSeatHeating (SetSeatHeatingRequest) returns (SetSeatHeatingResponse);
}

--------- VSIDL ---------
sdv_service_bundle {
  name: "SeatHeatingController"
  client {
    service: "SeatHeatingService"
  }
}
```

## How to Fix

Remove one of the conflicting services.

```textproto
--------- PROTO ---------
// Request to set seat heating
message SetSeatHeatingRequest {
  enum Seat {
    DRIVER = 0;
    PASSENGER = 1;
  }
  Seat seat = 1;
  SeatHeatingLevel level = 2;
}

// Response to setting seat heating
message SetSeatHeatingResponse {
  bool success = 1;
}

// Seat heating service
service SeatHeatingService {
  rpc SetSeatHeating (SetSeatHeatingRequest) returns (SetSeatHeatingResponse);
}


- // Seat heating service
- service SeatHeatingService {
-   rpc SetSeatHeating (SetSeatHeatingRequest) returns (SetSeatHeatingResponse);
- }

--------- VSIDL ---------
sdv_service_bundle {
  name: "SeatHeatingController"
  client {
    service: "SeatHeatingService"
  }
}
```
