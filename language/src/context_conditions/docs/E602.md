# **E602**: Types of publishers must be publications

## Description

A publisher uses a type that refers to a Protobuf message that doesn’t use the
`SdvPublication` annotation.

## Rationale (Why is this bad?)

**Missing Input**: VSIDLC needs certain metadata like the length of the message
queue to be able to generate code. Without this `SdvPublication` annotation,
this metadata is missing and VSIDLC cannot generate code.

## Error Example

```textproto
--------- PROTO ---------
message TirePressure {
  uint32 pressure = 1;
}
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  publisher {
    # ERROR: TirePressure does not use the SdvPublication annotation
    type: "TirePressure"
  }
}
```

## How to Fix

Add the `SdvPublication` annotation to the requested type.

```textproto
--------- PROTO ---------
message TirePressure {
+ option (.sdv.vsidl.v1.publication) = {
+   message_count: 8
+   model: SINGLE_PUB
+ };
  uint32 pressure = 1;
}
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  publisher {
    type: "TirePressure"
  }
}
```
