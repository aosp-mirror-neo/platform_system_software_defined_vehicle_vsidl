# **E103**: `rust_protobuf` target of Android.bp has multiple element in the Protos pointing to the same file

## Description

This warning informs the user that a single Protobuf file has been included
multiple times in the same library.

## Rationale (Why is this bad?)

**Inefficiency**: This warning causes no problem, just notify the user that
there is a more optimal way to write the `rust_protobuf` library definition

## Error Example

```textproto
rust_protobuf {
  name: "liba_proto",
  crate_name: "a_proto",
  protos: ["**/*.proto", "mya.proto"], # mya.proto will be matched by both the expression and the file definition.
}
```

## How to Fix

Avoid defining the multiple proto file name twice in the list of protos.

```textproto
rust_protobuf {
  name: "liba_proto",
  crate_name: "a_proto",
  protos: ["**/*.proto" ], @ every protofile is included just once
}
```
