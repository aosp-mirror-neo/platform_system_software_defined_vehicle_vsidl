# **E209**: Service bundle names must not be empty

## Description

Service names must not be the empty String.

## Rationale (Why is this bad?)

**Rust Syntax Violation**: Service bundle names are printed as struct names in
Rust. Rust does not allow empty struct names.

## Error Example

```textproto
sdv_service_bundle {
  # ERROR: Empty name
  name: ""
}
```

## How to Fix

Choose a non-empty name for the service bundle

```textproto
sdv_service_bundle {
  name: "Placeholder"
}
```
