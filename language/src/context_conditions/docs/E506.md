# **E506**: Android.bp `rust_protobuf` without `crate_name`

## Description

This is triggered when the Android.bp files processed by VISDLC defines a
`rust_protobuf` target not defining the `crate_name` attribute.

## Rationale (Why is this bad?)

**Soong Requirement**: `crate_name` is a mandatory attribute in Android.bp
targets. Not having a crate name would lead to a Soong error.

## Error Example

```textproto
rust_protobuf {
  name: "libmy_crate",
  protos: ["**/*.proto"],
}
```

## How to Fix

Add `crate_name` attribute to `rust_protobuf` target in Android.bp.

```textproto
rust_protobuf {
  name: "libmy_crate",
  crate_name: "my_crate",
  protos: ["**/*.proto"],
}
```
