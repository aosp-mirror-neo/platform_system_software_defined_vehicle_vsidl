# **E512**: Proto message should not contain any loop

## Description

A message in a pubsub service should not contain any loop which included
self-reference or cross-reference.

## Rationale (Why is this bad?)

A loop in pubsub service would cause infinite loop while calculating the size of
message.

## Error Example

**self reference loop**

```textproto
message SelfReferenceMessage {
  int32 int_value = 1;
  SelfReferenceMessage self_reference = 2;
}
```

**cross reference loop**

```textproto
message CrossReferenceMessageFirst {
  int32 int_value = 1;
  CrossReferenceMessageSecond msg = 2;
}

message CrossReferenceMessageSecond {
  int32 int_value = 1;
  CrossReferenceMessageFirst msg = 2;
}
```

## How to Fix

Remove the field that cause the loop.

**fix the self reference loop**

```textproto
message SelfReferenceMessage {
    int32 int_value = 1;
}
```

**fix the cross reference loop**

```textproto
message CrossReferenceMessageFirst {
    int32 int_value = 1;
    CrossReferenceMessageSecond msg = 2;
}

message CrossReferenceMessageSecond {
    int32 int_value = 1;
}
```
