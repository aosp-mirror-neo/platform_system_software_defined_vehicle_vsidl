# **E60A**: RPC client uses a type that does not exist as a Proto RPC service

## Description

The services RPC clients want to use must be defined in Protobuf as RPC
services.

## Rationale (Why is this bad?)

**Uncompilable Generated Code**: Code generated from this input would refer to
identifiers that do not exist, leading to a Rust error.

## Error Example

```textproto
--------- PROTO ---------
// empty
--------- VSIDL ---------
sdv_service_bundle {
  name: "SeatHeatingController"
  client {
    # ERROR: There's no Protobuf message defined for this
    service: "SeatHeatingService"
  }
}
```

## How to Fix

Define the missing RPC service in Protobuf.

```textproto
--------- PROTO ---------
+ // Request to set seat heating
+ message SetSeatHeatingRequest {
+   enum Seat {
+     DRIVER = 0;
+     PASSENGER = 1;
+   }
+   Seat seat = 1;
+   SeatHeatingLevel level = 2;
+ }

+ // Response to setting seat heating
+ message SetSeatHeatingResponse {
+   bool success = 1;
+ }

+ // Seat heating service
+ service SeatHeatingService {
+   rpc SetSeatHeating (SetSeatHeatingRequest) returns (SetSeatHeatingResponse);
+ }

--------- VSIDL ---------
sdv_service_bundle {
  name: "SeatHeatingController"
  client {
    service: "SeatHeatingService"
  }
}
```
