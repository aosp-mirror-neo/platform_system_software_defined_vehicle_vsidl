# **E612**: Proto library points to a filegroup that does not exist

## Description

This error occurs when a Protobuf file defined in the Catalog points to a
filegroup that is not defined.

## Rationale (Why is this bad?)

VSIDLC cannot generate code using a library that points to proto files and
messages that are unknown.

## Error Example

```textproto
rust_protobuf {
  name: "libtest_rust_proto",
  crate_name: "test_rust_proto",
  protos: [":undefined_filegroup"],
}
```

## How to Fix

Be sure that all the element inside protos list of `rust_protobuf` in the
catalog are valid and defined

```textproto
rust_protobuf {
  name: "libtest_rust_proto",
  crate_name: "test_rust_proto",
  protos: [":undefined_filegroup"],
}

filegroup {
  name: "undefined_filegroup",
  src: ["a.proto", "b.proto"],
}
```
