# **E310**: filegroup target must be unique across all Android.bp

## Description

Occurs when multiple filegroup targets defined in Android.bp have the same
“name”.

## Rationale (Why is this bad?)

All Soong targets must be unique, including filegroup.

## Error Example

```textproto
filegroup {
  name: "filegroup_a",
  srcs: ["A.proto"],
}
filegroup {
  name: "filegroup_a",
  srcs: ["B.proto"],
}
```

## How to Fix

Using different names for different filegroup targets.

```textproto
filegroup {
  name: "filegroup_a",
  srcs: ["A.proto"],
}
filegroup {
  name: "filegroup_b",
  srcs: ["B.proto"],
}
```
