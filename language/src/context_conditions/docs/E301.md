# **E301**: User-defined target name in `build_cfg` must not conflict with generated names

## Description

The target names defined by the user cannot be the same as auto-generated target
names.

## Rationale (Why is this bad?)

**Soong Requirement**: All target names across all Android.bp files need to be
unique.

## Error Example

```textproto
sdv_service_bundle {
  name: "DuplicatedTargetName"
}

sdv_service_bundle {
  name: "DuplicatedTargetName2"
  build_cfg {
    # Error: The user-defined name clashes with the target name of DuplicatedTargetName
    target_name: "sdv_test_duplicated_target_name"
  }
}
```

## How to Fix

Be sure that `build_cfg.target_name` field is different from the auto-generated.

```textproto
sdv_service_bundle {
  name: "DuplicatedTargetName"
}

sdv_service_bundle {
  name: "DuplicatedTargetName2"
  build_cfg {
    target_name: "sdv_test_duplicated_target_name_two"
  }
}
```
