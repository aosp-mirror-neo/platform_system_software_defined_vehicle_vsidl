# **E406**: Publisher capacity must be at least 2 and an even number

## Description

This error occurs when a publisher defines a `capacity` that is less than 2 or
is not an even number.

## Rationale (Why is this bad?)

**Comms Stack Requirement**: The underlying communication stack requires the
message buffer capacity to be at least 2 and an even number for correct memory
alignment and queue management. Providing an invalid capacity would lead to
runtime errors or system instability.

## Error Example

```vsidl
publisher {
  message: "TirePressure"
  # ERROR: capacity must be at least 2 and even
  capacity: 1
}
```

```vsidl
publisher {
  message: "TirePressure"
  # ERROR: capacity must be at least 2 and even
  capacity: 3
}
```

## How to Fix

Update the `capacity` field to be at least 2 and an even number (e.g., 2, 4, 8,
16, etc.).

```vsidl
publisher {
  message: "TirePressure"
  capacity: 8
}
```
