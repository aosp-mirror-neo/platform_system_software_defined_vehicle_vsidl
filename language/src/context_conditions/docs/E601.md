# **E601**: Types of publishers must exist

## Description

Types that publishers use must be defined as messages with an `SdvPublication`
annotation in Protobuf.

## Rationale (Why is this bad?)

**Uncompilable Code**: If there is no such message in Protobuf, the generated
Rust code couldn’t be compiled because it refers to a struct that doesn’t exist.

## Error Example

```textproto
--------- PROTO ---------
// empty
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  publisher {
    # ERROR: There's no Protobuf message defined for this
    type: "TirePressure"
  }
}
```

## How to Fix

Add a Protobuf message for the requested type.

```textproto
--------- PROTO ---------
+ message TirePressure {
+   option (.sdv.vsidl.v1.publication) = {
+     message_count: 8
+     model: SINGLE_PUB
+   };
+   uint32 pressure = 1;
+ }
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  publisher {
    type: "TirePressure"
  }
}
```
