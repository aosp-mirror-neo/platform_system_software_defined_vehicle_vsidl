# E40A: RPC client channel maps to an existing server-side channel definition

## Description

This error is issued if an RPC client specifies a channel for a service, but
there is no RPC server defined for the same service on that channel. This
ensures that clients are correctly mapped to their corresponding servers.

## Rationale (Why is this bad?)

Without this field, clients will crash when trying to instantiate them.

## Examples

### Incorrect

```vsidl
service_bundle ClientBundle {
    client {
        service: "MyService"
        channel: "main"
    }
}

service_bundle ServerBundle {
    server {
        service: "MyService"
        channel: "other" // Mismatch: client uses "main", server uses "other"
    }
}
```

### Correct

```vsidl
service_bundle ClientBundle {
    client {
        service: "MyService"
        channel: "main"
    }
}

service_bundle ServerBundle {
    server {
        service: "MyService"
        channel: "main"
    }
}
```
