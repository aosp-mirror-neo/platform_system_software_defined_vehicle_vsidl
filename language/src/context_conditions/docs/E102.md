# **E102**: `rust_protobuf` target of Android.bp has invalid proto

## Description

This warning occurs when an Android.bp file contains a `rust_protobuf` target
with an element in the source list that does not match any file. This could be
expected, in case the protobuf file will be created later, but could also show
that there is a type in the Android.bp definition.

## Rationale (Why is this bad?)

**Possibility for uncompilable code**: If the user is expecting file
`my_a.proto` to be in `rust_protobuf` library `liba_proto`, but it’s not,
`vsidlc` will not be able to generate a file for messages defined in
`my_a.proto`.

## Error Example

```textproto
rust_protobuf {
  name: "liba_proto",
  crate_name: "a_proto",
  protos: ["mya.proto"], # name with typo, not matching any file
}

// catalog folder
catalog -> my_a.proto

// the messages defined in a.proto are not build inside liba_proto, due to typo in name.
```

## How to Fix

Be sure the list of file in the protos property of `rust_protobuf` matches
existing proto files

```textproto
rust_protobuf {
  name: "liba_proto",
  crate_name: "a_proto",
  protos: ["my_a.proto"], # name fixed, matching the files system proto file
}
```
