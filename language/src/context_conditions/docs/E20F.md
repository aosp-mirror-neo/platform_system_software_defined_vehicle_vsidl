# **E20F**: Topic name exceeds length limit

## Description

This error occurs when a publisher or subscriber defines a topic name that
exceeds the maximum length limit of 127 characters.

## Rationale (Why is this bad?)

**Comm Stack Limit**: The underlying communication stack sets a limit of 127
characters for topics to ensure they fit in internal buffers. Exceeding this
limit can lead to communication failures or undefined behavior.

## Error Example

```vsidl
publisher {
  message: "TirePressure"
  # ERROR: This very long topic name exceeds 127 characters
  topic: "this-is-a-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-very-long-topic"
}
```

## How to Fix

Shorten the topic name to be at most 127 characters.

```vsidl
publisher {
  message: "TirePressure"
  topic: "short-topic"
}
```
