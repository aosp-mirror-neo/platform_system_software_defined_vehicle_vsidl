# **E20D**: Topics must follow kebab case convention

## Description

This error occurs when a publisher or subscriber defines a topic that does not
follow the kebab case naming convention.

## Rationale (Why is this bad?)

**Consistency and Interoperability**: Enforcing a consistent naming convention
across all topics improves readability and reduces the likelihood of errors when
integrating different services. Kebab case is the standard convention for topics
in the VSIDL ecosystem.

A valid kebab case name: * Starts with a lowercase letter `[a-z]`. * Contains
only lowercase alphanumeric characters `[a-z0-9]` and hyphen `-`. * Does not
contain consecutive hyphens `--`. * Does not end with a hyphen `-`.

## Error Example

```vsidl
publisher {
  message: "Speed"
  # ERROR: "MainTopic" is not in kebab case
  topic: "MainTopic"
}
```

## How to Fix

Rename the topic to follow the kebab case convention.

```vsidl
publisher {
  message: "Speed"
  topic: "main-topic"
}
```
