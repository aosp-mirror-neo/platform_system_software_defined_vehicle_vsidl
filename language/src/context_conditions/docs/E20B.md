# **E20B**: Service bundle names must start with a unicode XID start character.

## Description

The name must only contain unicode XID continue characters. See list of allowed
characters
[here](https://util.unicode.org/UnicodeJsps/list-unicodeset.jsp?a=%5B%3AXID_Continue%3A%5D&abb=on&g=&i=").

## Rationale (Why is this bad?)

**Rust Syntax Violation**: Service bundle names are printed as struct names in
Rust. Rust [requires](https://doc.rust-lang.org/reference/identifiers.html) a
XID continue characters in identifiers.

## Error Example

```textproto
sdv_service_bundle {
  # ERROR: Non-XID-CONTINUE character (space) in name
  name: "Place holder"
}
```

## How to Fix

Remove the non XID Continue character from the service bundle name

```textproto
sdv_service_bundle {
  name: "Placeholder"
}
```
