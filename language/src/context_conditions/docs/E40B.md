# E40B: RPC channel must only be used by one service

## Description

This error is issued if multiple RPC servers for different services use the same
RPC channel. Each channel must be uniquely associated with a single RPC service
to ensure clear communication routing.

## Examples

### Incorrect

```vsidl
service_bundle MyService {
    server {
        service: "ServiceA"
        channel: "main"
    }
    server {
        service: "ServiceB"
        channel: "main" // Conflict: "main" already used by ServiceA
    }
}
```

### Correct

```vsidl
service_bundle MyService {
    server {
        service: "ServiceA"
        channel: "channel-a"
    }
    server {
        service: "ServiceB"
        channel: "channel-b"
    }
}
```
