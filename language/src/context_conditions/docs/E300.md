# **E300**: Multiple publishers are defined for the same MultiPub type in the same service bundle

## Description

There may not be two publishers publishing the same `MULTI_PUB` type inside the
same service bundle, even if they use different service unit names.

## Rationale (Why is this bad?)

**Uncompilable Generated Code**: Given the current structure of the generated
code, this would lead to code that cannot be compiled.

## Error Example

```textproto
sdv_service_bundle {
  name: "ServiceBundleA"

  publisher {
    type: "Speed"
  }

  publisher {
    # Error: This multipub type is already used by a publisher in this service bundle
    type: "Speed"
    service_unit_name: "my-pub"
  }
}

```

## How to Fix

Move one of the publishers to a different service bundle.

```textproto
sdv_service_bundle {
  name: "ServiceBundleA"

  publisher {
    type: "Speed"
  }

- publisher {
-   type: "Speed"
-   service_unit_name: "my-pub"
- }
}

+ sdv_service_bundle {
+   name: "ServiceBundleB"
+
+  publisher {
+    type: "Speed"
+    service_unit_name: "my-pub"
+  }
+ }

```
