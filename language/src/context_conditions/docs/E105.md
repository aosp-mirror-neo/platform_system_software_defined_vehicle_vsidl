# **E105**: Filegroup target sources points to non-existing files

## Description

This warning notifies the user that a filegroup defined in Android.bp does not
point to any existing file. This can be caused by a typo or defining a target in
the wrong folder.

## Rationale (Why is this bad?)

**Likely unintended input**: The user believes a valid filegroup has been
defined to group a subset of files, but this is not the case.

## Error Example

```textproto
filegroup {
  name: "empty_filegroup_sample",
  srcs: ["not_existing_protos/*.proto"], # folder specified does not exists
}

// catalog folder
catalog -> existing_protos/a.proto
        -> existing_vsidlc/a.vsidlc
```

## How to Fix

Be sure that the list of `srcs` in the filegroup matches at least one file.

```textproto
filegroup {
  name: "empty_filegroup_sample",
  srcs: ["existing_protos/*.proto"],
}
```
