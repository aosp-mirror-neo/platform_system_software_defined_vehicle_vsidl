# **E514**: Bidirectional streaming methods are not supported

## Description

Bidirectional streaming methods are not supported in RPC. Any service that
declares a method with the `stream` keyword on both its request and response
types will be rejected.

## Rationale (Why is this bad?)

**Unsupported Feature**: The underlying communication stack does not support
bidirectional streaming. Declaring such a method is invalid as it would result
in non-functional or uncompilable generated code.

## Error Example

```textproto
service StreamingRpc {
  # This bidirectional streaming method is not supported
  rpc rpcmethod(stream google.protobuf.Any) returns (stream google.protobuf.Any) {}
}
```

## How to Fix

**Alternative 1**: Remove `stream` from both the request and response to make it
a unary (non-streaming) method.

```textproto
service StreamingRpc {
-  rpc rpcmethod(stream google.protobuf.Any) returns (stream google.protobuf.Any) {}
+  rpc rpcmethod(google.protobuf.Any) returns (google.protobuf.Any) {}
}
```

**Alternative 2**: Remove `stream` from response, make it a client streaming
method.

```textproto
service StreamingRpc {
-  rpc rpcmethod(stream google.protobuf.Any) returns (stream google.protobuf.Any) {}
+  rpc rpcmethod(stream google.protobuf.Any) returns (google.protobuf.Any) {}
}
```

**Alternative 3**: Remove `stream` from request, make it a server streaming
method.

```textproto
service StreamingRpc {
-  rpc rpcmethod(stream google.protobuf.Any) returns (stream google.protobuf.Any) {}
+  rpc rpcmethod(google.protobuf.Any) returns (stream google.protobuf.Any) {}
}
```
