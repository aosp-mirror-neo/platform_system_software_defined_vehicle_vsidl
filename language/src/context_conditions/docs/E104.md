# **E104**: Multiple `rust_protobuf` target of Android.bp points to the same file

## Description

This warning notifies the user that a protobuf file has been included in
multiple `rust_protobuf` targets in Android.bp . This can be triggered by either
multiple `rust_protobuf` targets defined in the same Android.bp or different
`rust_protobuf` targets defined in multiple Android.bp files.

## Rationale (Why is this bad?)

**Undefined Behavior**: vsidlc will randomly choose one of the `rust_protobuf`
libraries when generating code. This does not provide any guarantee that the
smaller library is used and could lead to generating a library bigger than
required.

## Error Example

```textproto
rust_protobuf {
  name: "libmessages_protos",
  crate_name: "messages_protos",
  protos: [
    "protos/message_a.proto",
    "protos/message_b.proto",
    "protos/message_c.proto",
  ],
}

rust_protobuf {
  name: "libmessage_a_protos",
  crate_name: "message_a_protos",
  protos: [
    "protos/message_a.proto",
  ],
}
```

## How to Fix

It will be ideal to not have `rust_protobuf` libraries overlapping the same
content. Without overlap the generated code will always use the smaller possible
library. For example the user could define a single library per proto message

```textproto
rust_protobuf {
  name: "libmessage_a_protos",
  crate_name: "message_a_protos",
  protos: [
    "protos/message_a.proto",
  ],
}
rust_protobuf {
  name: "libmessage_b_protos",
  crate_name: "message_b_protos",
  protos: [
    "protos/message_b.proto",
  ],
}
rust_protobuf {
  name: "libmessage_c_protos",
  crate_name: "message_c_protos",
  protos: [
    "protos/message_c.proto",
  ],
}
```
