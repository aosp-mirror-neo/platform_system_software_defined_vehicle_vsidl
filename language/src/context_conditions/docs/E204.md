# **E204**: User-defined service unit names must not use hyphen as last character

## Description

User-defined service unit names must not use hyphen as last character

## Rationale (Why is this bad?)

**Comm Stack Requirement Violation**: The user-defined name is used as-is in
generated code, hence it must follow the name conventions for unit names
enforced by Comm Stack.

## Error Example

```textproto
server {
  service: "sdv.test.DummyRpc"
  # Error: User-defined name ends with hyphen
  service_unit_name: "test-"
}
```

## How to Fix

Change the user-defined name to remove the trailing hyphen

```textproto
server {
  service: "sdv.test.DummyRpc"
  service_unit_name: "test"
}
```
