# **E607**: Publisher uses channel for a Proto type that does not use channels

## Description

A publisher uses a channel for a Protobuf publication that does not use
`channels_enum` and the specified channel is not `UNIQUE`.

## Rationale (Why is this bad?)

**Uncompilable Generated Code**: The code generated from this input would refer
to identifiers that do not exist, leading to a Rust compiler error.

## Error Example

```textproto
--------- PROTO ---------
message TirePressure {
  option (.sdv.vsidl.v1.publication) = {
    message_count: 8
    model: SINGLE_PUB
  };
  uint32 pressure = 1;
}
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  publisher {
    type: "TirePressure"
    # ERROR: TirePressure does not use a channels_enum
    channel: "REAR_RIGHT"
  }
}
```

## How to Fix

**Alternative 1**: Add an `channels_enum` declaration that refers to an enum
that contains the channel specified by the publisher.

```textproto
--------- PROTO ---------
+ enum Location {
+   FRONT_LEFT = 0;
+   FRONT_RIGHT = 1;
+   REAR_RIGHT = 2;
+ }
message TirePressure {
  option (.sdv.vsidl.v1.publication) = {
    channels_enum: "Location"
    message_count: 8
    model: SINGLE_PUB
  };
  uint32 pressure = 1;
}
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  publisher {
    type: "TirePressure"
    channel: "REAR_RIGHT"
  }
}
```

**Alternative 2**: Remove the channel declaration from the publisher, which
means the publisher will use the `UNIQUE` channel.

```textproto
--------- PROTO ---------
message TirePressure {
  option (.sdv.vsidl.v1.publication) = {
    message_count: 8
    model: SINGLE_PUB
  };
  uint32 pressure = 1;
}
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  publisher {
    type: "TirePressure"
-   channel: "REAR_RIGHT"
  }
}
```
