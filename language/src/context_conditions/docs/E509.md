# **E509**: Android.bp filegroup without name

## Description

VSIDLC triggers this error when processing an Android.bp file containing a
`filegroup` target with a missing `srcs`.

## Rationale (Why is this bad?)

The only attribute processed by VSIDLC for `filegroup` targets is the list of
`srcs`. Therefore, that's a mandatory field for VSIDLC.

## Error Example

```textproto
filegroup {
  name: "no_srcs_filegroup",
}
```

## How to Fix

Define the srcs field as part of filegroup.

```textproto
filegroup {
  name: "all_protos",
  srcs: ["*.proto"],
}
```
