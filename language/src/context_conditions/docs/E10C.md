# **E10C**: Catalog is empty

## Description

This warning occurs when the parsed catalog does not contain any `.vsidl` files,
or when all `.vsidl` files in the catalog are empty or contain no relevant definitions
(e.g., no Service Bundles).

## Rationale (Why is this bad?)

If the catalog is empty or contains no valid definitions, the VSIDL compiler will
not generate any middleware code. This is usually unintended and indicates that the
catalog path might be incorrect, or the files are missing or empty.

## Error Example

Running `vsidlc` on an empty directory, or a directory containing only empty `.vsidl` files.

## How to Fix

Ensure that the catalog path provided to `vsidlc` is correct and contains valid `.vsidl` files
with Service Bundle definitions.
