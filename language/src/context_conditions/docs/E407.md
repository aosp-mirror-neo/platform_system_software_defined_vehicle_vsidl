# **E407**: Publisher capacity is mandatory in latest VSIDL syntax

## Description

This error occurs when a publisher in a VSIDL file does not specify the
`capacity` field while using the latest VSIDL syntax.

## Rationale (Why is this bad?)

**Ambiguous Configuration**: In the latest VSIDL syntax, the `capacity` field is
used to configure the underlying communication stack's message buffer. Leaving
it out makes the configuration ambiguous and may lead to incorrect system
behavior. Every publisher must explicitly declare its capacity to ensure
consistent and predictable performance.

## Error Example

```vsidl
publisher {
  message: "TirePressure"
  channel: "FRONT_LEFT"
  # ERROR: Missing mandatory 'capacity' field
}
```

## How to Fix

Add the `capacity` field to the publisher definition. The value must be at least
2 and an even number.

```vsidl
publisher {
  message: "TirePressure"
  channel: "FRONT_LEFT"
  capacity: 8
}
```
