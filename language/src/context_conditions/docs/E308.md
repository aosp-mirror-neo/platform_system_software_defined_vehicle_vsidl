# **E308**: Service unit names may not occur multiple times in the same service bundle

## Description

Service unit names must be unique within a service bundle.

## Rationale (Why is this bad?)

**Undefined Behavior**: Service Units are identified via their fully-qualified
channel names. The name contains the service bundle name’s fully-qualified name
followed by the service unit name. Having multiple service units with the same
name would lead to undefined behavior when resolving the name using service
discovery.

## Error Example

```textproto
sdv_service_bundle {
  name: "TestConflictNameWithinServiceBundle"
  publisher {
    type: "TirePressureFront"
    channel: "LEFT"
  }
  # ERROR: Same service unit name as the publisher above
  publisher {
    type: "TirePressure"
    channel: "FRONT_LEFT"
  }
}
```

## How to Fix

User user-defined service unit names to resolve the conflict.

```textproto
sdv_service_bundle {
  name: "TestConflictNameWithinServiceBundle"
  publisher {
    type: "TirePressureFront"
    channel: "LEFT"
  }
  publisher {
    type: "TirePressure"
    channel: "FRONT_LEFT"
+   service_unit_name: "front-left-pressure"
  }
}
```
