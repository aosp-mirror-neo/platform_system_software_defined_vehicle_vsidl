# **E513**: Proto message exceeds max size limit

## Description

The calculated size of a message in a pubsub service exceeds the maximum size
limit for a protobuf message.

## Rationale (Why is this bad?)

Protobuf messages are limited to 2GiB (see:
https://protobuf.dev/programming-guides/proto-limits/). A message that is larger
than this limit will cause issues during the serialization process.

## Error Example

```textproto
message LargeMessage {
  # set a large value to the variable type so it exceeds the limit
  string large_string = 1 [(sdv.vsidl.v1.variable_type_max_size) = 2147483647];
}
```

## How to Fix

Reduce the annotated sizes of fields in the message so that the total calculated
size is less than 2GiB.

```textproto
message LargeMessage {
  string large_string = 1 [(sdv.vsidl.v1.variable_type_max_size) = 500];
}
```
