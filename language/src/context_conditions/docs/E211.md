# **E211**: Proto package name may not exceed a length limit

## Description

Proto package names may not be longer than 127 characters.

## Rationale (Why is this bad?)

**Comm Stack Limit**: The underlying communication stack sets a limit of 127
characters for names to ensure they fit within fixed-size buffers. While the
proto package name itself might be part of a larger FQIN, long package names can
cause the final unit type name to exceed the limit.

## Error Example

```proto
package com.google.sdv.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.very.long;

message MyMessage {
  option (.sdv.vsidl.v1.publication) = {
    model: SINGLE_PUB
    message_count: 8
  };
  // ...
}
```

## How to Fix

Shorten the proto package name to be at most 127 characters.
