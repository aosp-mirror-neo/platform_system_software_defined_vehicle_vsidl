# **E609**: Subscriber uses a type that does exist as a Proto publication, but does not have the channel requested by the subscriber

## Description

A subscriber contains a channel that is not a channel defined in Protobuf.

## Rationale (Why is this bad?)

**Uncompilable Generated Code**: Code generated from this input would refer to
identifiers that do not exist, leading to a Rust error.

## Error Example

```textproto
--------- PROTO ---------
enum Location {
FRONT_LEFT = 0;
FRONT_RIGHT = 1;
}
message TirePressure {
  option (.sdv.vsidl.v1.publication) = {
    channels_enum: "Location"
    message_count: 8
    model: SINGLE_PUB
  };
  uint32 pressure = 1;
}
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  subscriber {
    type: "TirePressure"
    # ERROR: REAR_RIGHT is not defined as a channel in the Location enum
    channel: "REAR_RIGHT"
  }
}
```

## How to Fix

**Alternative 1**: Choose one of the existing channels instead.

```textproto
--------- PROTO ---------
enum Location {
  FRONT_LEFT = 0;
  FRONT_RIGHT = 1;
}
message TirePressure {
  option (.sdv.vsidl.v1.publication) = {
    channels_enum: "Location"
    message_count: 8
    model: SINGLE_PUB
  };
  uint32 pressure = 1;
}
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  subscriber {
    type: "TirePressure"
-   channel: "REAR_RIGHT"
+   channel: "FRONT_RIGHT"
  }
}
```

**Alternative 2**: Add the missing channel to the enum.

```textproto
--------- PROTO ---------
enum Location {
  FRONT_LEFT = 0;
  FRONT_RIGHT = 1;
+ REAR_RIGHT = 2;
}
message TirePressure {
  option (.sdv.vsidl.v1.publication) = {
    channels_enum: "Location"
    message_count: 8
    model: SINGLE_PUB
  };
  uint32 pressure = 1;
}
--------- VSIDL ---------
sdv_service_bundle {
  name: "TirePressureSensor"
  subscriber {
  type: "TirePressure"
  channel: "REAR_RIGHT"
  }
}
```
