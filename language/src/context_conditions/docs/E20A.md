# **E20A**: Service bundle names must start with a unicode XID start character

## Description

The name must start with a unicode XID start character. See list of allowed
characters
[here](https://util.unicode.org/UnicodeJsps/list-unicodeset.jsp?a=%5B%3AXID_Start%3A%5D&abb=on&g=&i=%20).

## Rationale (Why is this bad?)

**Rust Syntax Violation**: Service bundle names are printed as struct names in
Rust. Rust [requires](https://doc.rust-lang.org/reference/identifiers.html) a
XID Start characters at the start of an identifier.

## Error Example

```textproto
sdv_service_bundle {
  # ERROR: Non-XID-START character as first character
  name: "$Placeholder"
}
```

## How to Fix

Replace the non XID START character from the service bundle name

```textproto
sdv_service_bundle {
  name: "SPlaceholder"
}
```
