# **E10D**: Existing main.rs detected during service generation

## Description

VSIDL detected that a `main.rs` file already exists in the target directory for a service bundle.
To prevent overwriting potential manual changes or custom logic in your `main.rs`, VSIDL has
saved the newly generated version as `main.rs.gen`.

## Rationale (Why is this bad?)

Automatically overwriting an existing `main.rs` could lead to the loss of custom implementation
logic, manual service registrations, or other modifications that are not yet part of the VSIDL
definitions.

## Error Example

Generating code for a service bundle where `src/main.rs` already exists in the output directory.

## How to Fix

You should review the differences between your existing `main.rs` and the newly generated `main.rs.gen`.
You may need to manually merge new service registrations or other changes into your existing `main.rs`.

You can use a tool like `diff` to see the changes:

```bash
diff --color path/to/src/main.rs path/to/src/main.rs.gen
```

After merging the necessary changes, you can safely delete the `main.rs.gen` file.
