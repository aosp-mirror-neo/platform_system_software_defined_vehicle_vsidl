# **E202**: User-defined service unit name contains invalid character

## Description

All characters of a user-defined service unit name must be lowercase
alphanumeric or a hyphen: \[a-z0-9\\-\]

## Rationale (Why is this bad?)

**Comm Stack Requirement Violation**: The user-defined name is used as-is in
generated code, hence it must follow the name conventions for unit names
enforced by Comm Stack.

## Error Example

```textproto
server {
  service: "sdv.test.PlaceholderRpc"
  # Error: User-defined name contains '?'
  service_unit_name: "test?"
}
```

## How to Fix

Change the user-defined name to use only lowercase alphanumeric characters or a
hyphen: \[a-z0-9\\-\]

```textproto
server {
  service: "sdv.test.PlaceholderRpc"
  service_unit_name: "test"
}
```
