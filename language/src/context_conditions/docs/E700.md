# **E700**: Parser Error: Syntax or Structure Violation

## Description

A **Parser Error** occurs when the parser cannot understand or process the
source code because it violates the expected **syntax** or **grammatical
structure** of the language or format.

## Rationale (Why is this bad?)

The parser's primary job is to create a structured internal representation (like
an **Abstract Syntax Tree (AST)**) from the text. If the text deviates from the
defined rules, the parser fails to build this structure, making it impossible
for the system to execute, compile, or correctly interpret the program or data.
It stops the entire process.

## Error Example

```textproto
# ERROR: Missing opening brace
service_bundle
  name: "SeatHeatingController"
  subscriber {
    type: "SeatHeatingService"
  }
}
```
