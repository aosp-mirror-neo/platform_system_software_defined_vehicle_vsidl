# **E106**: Redundant `UNIQUE` channel is specified in VSIDL file

## Description

This warning notifies the user that an `UNIQUE` channel specification is
redundant for publisher/subscriber in a VSIDL file.

## Rationale (Why is this bad?)

The `UNIQUE` channel is default behavior of a publisher/subscriber if the
publication does not declare a channels_enum. There is no need to specify it.

## Error Example

-   redundant UNIQUE channel of publisher

```textproto
sdv_service_bundle {
  name: "PublisherWithExplicitUniqueChannel"

  publisher {
    type: "FuelLevel"
    # FuelLevel does not use channels_enum, UNIQUE specification is redundant
    channel: "UNIQUE"
  }
}
```

-   redundant UNIQUE channel of subscriber

```textproto
sdv_service_bundle {
  name: "SubscriberWithUniqueChannel"

  subscriber {
    type: "FuelLevel"
    # FuelLevel does not use channels_enum, UNIQUE specification is redundant
    channel: "UNIQUE"
  }
}
```

## How to Fix

Remove the UNIQUE channel specification in VSIDL file

-   Fix for redundant UNIQUE channel of publisher

```textproto
sdv_service_bundle {
  name: "PublisherWithExplicitUniqueChannel"

  publisher {
    type: "FuelLevel"
  }
}
```

-   Fix for redundant UNIQUE channel of subscriber

```textproto
sdv_service_bundle {
  name: "SubscriberWithUniqueChannel"

  subscriber {
    type: "FuelLevel"
  }
}
```
