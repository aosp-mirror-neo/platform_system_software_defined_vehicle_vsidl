# This check is deprecated!

Service bundles do not own unit types anymore. This check is not executed
anymore.

# **E60E**: Subscriber uses a type that does not exist as a unit type

## Description

No service bundle owns the unit type that the subscriber uses.

## Rationale (Why is this bad?)

**Discovery Impossible**: Unit types use a service bundle as part of their
unique identifier. If no service bundle owns the unit type, this part is
missing.

## Error Example

```textproto
sdv_service_bundle {
  name: "TirePressureSensor"
  subscriber {
    # ERROR: No service bundle owns this type as a unit type
    type: "TirePressure"
  }
}
```

## How to Fix

Add the missing unit type ownership

```textproto
sdv_service_bundle {
  name: "TirePressureSensor"
  subscriber {
    type: "TirePressure"
  }
+ unit_type {
+  type: "TirePressure"
+ }
}
```
