# E20E: RPC channel must be in lowercase kebab case

## Description

RPC channels must use lowercase kebab case (e.g., `main-channel`). They must: -
Start with a lowercase letter. - Contain only lowercase letters, digits, and
hyphens. - Not end with a hyphen. - Not contain consecutive hyphens.

## Examples

### Incorrect

```vsidl
service_bundle MyService {
    server {
        service: "MyService"
        channel: "MainChannel" // camelCase is not allowed
    }
}
```

### Correct

```vsidl
service_bundle MyService {
    server {
        service: "MyService"
        channel: "main-channel"
    }
}
```
