# **E408**: Topic is mandatory in latest VSIDL syntax

## Description

This error occurs when a publisher or a subscriber in a VSIDL file does not
specify the `topic` field while using the latest VSIDL syntax.

## Rationale (Why is this bad?)

**Ambiguous Configuration**: In the latest VSIDL syntax, the `topic` field is
used to explicitly define the communication topic for a publisher or subscriber.
Implicit default topics are not supported. Every publisher and subscriber must
explicitly declare its topic.

## Error Example

```vsidl
publisher {
  message: "TirePressure"
  capacity: 8
  # ERROR: Missing mandatory 'topic' field
}

subscriber {
  message: "TirePressure"
  # ERROR: Missing mandatory 'topic' field
}
```

## How to Fix

Add the `topic` field to the publisher or subscriber definition.

```vsidl
publisher {
  message: "TirePressure"
  capacity: 8
  topic: "front_left"
}

subscriber {
  message: "TirePressure"
  topic: "front_left"
}
```
