# **E60C**: Channels enum of SDV Publication annotation must be defined

## Description

The `channels_enum` in an `SdvPublication` annotation refers to an enum that
does not exist.

## Rationale (Why is this bad?)

Uncompilable Generated Code: The generated code would refer to identifiers that
do not exist, leading to a Rust compiler error.

## Error Example

```textproto
message TirePressure {
  option (.sdv.vsidl.v1.publication) = {
    # ERROR this enum is undefined
    channels_enum: "Location"
    message_count: 8
    model: SINGLE_PUB
  };
  uint32 pressure = 1;
}
```

## How to Fix

Define the missing enum in Protobuf.

```textproto
+  enum Location {
+   FRONT_LEFT = 0;
+   FRONT_RIGHT = 1;
+ }
message TirePressure {
  option (.sdv.vsidl.v1.publication) = {
    channels_enum: "Location"
    message_count: 8
    model: SINGLE_PUB
  };
  uint32 pressure = 1;
}
```
