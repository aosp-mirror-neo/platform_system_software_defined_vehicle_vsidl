# **E502**: Service unit name may not exceed a length limit

## Description

Service unit names may not be longer than 127 characters.

## Rationale (Why is this bad?)

**Comm Stack Limit**: Comms Stack sets a limit of 127 characters for service
unit names to ensure it fits in the buffer length. Thus, Middleware can’t choose
names exceeding this limit.

## Error Example

```textproto
package: "com.sdv.google.test.this.is.a.very.very.very.long.package.name"
sdv_service_bundle {
  name: "GeneratedNameTooLong"
  publisher {
    type: "ThisIsAVeryLongNameThatToghetherWithThePackageNameExceedsTheLimit"
  }
}
```

## How to Fix

Use user-defined service unit names to assign shorter names.

```textproto
package: "com.sdv.google.test.this.is.a.very.very.very.long.package.name"
sdv_service_bundle {
  name: "GeneratedNameTooLong"
  publisher {
    type: "ThisIsAVeryLongNameThatToghetherWithThePackageNameExceedsTheLimit"
+   service_unit_name: "short-name"
  }
}
```
