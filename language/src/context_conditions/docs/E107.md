# **E107**: Unnecessary fully-qualified name specified in VSIDL file

## Description

This warning notifies the user that fully-qualified name specified is
unnecessary for `type` of publisher/subscriber or `service` of server/client.

## Rationale (Why is this bad?)

When the package of a proto message is the same as (or a subpackage of) the
VSIDL file's package, specifying the fully-qualified name is redundant. Using
the shorter, relative name improves readability and conciseness.

## Error Example

proto file

```textproto
package: "sdv.vsidl.test"
```

VSIDL FQN Sample 1

```textproto
package: "sdv.vsidl.test"

sdv_service_bundle {
  name: "TireStatusProducer"
  server {
    # unnecessary fully-qualified name since proto file is using the same package name
    service: "sdv.vsidl.test.TireStatus"
  }
}

sdv_service_bundle {
  name: "TireStatusConsumer"
  client {
    # unnecessary fully-qualified name since proto file is using the same package name
    service: "sdv.vsidl.test.TireStatus"
  }
}
```

VSIDL FQN Sample 2

```textproto
package: "sdv.vsidl"

sdv_service_bundle {
  name: "PublishingBundle"
  publisher {
    # unnecessary fully-qualified name since proto file is using the subpackage name
    type: "sdv.vsidl.test.TirePressure"
  }
}

sdv_service_bundle {
  name: "SubscribingBundle"
  subscriber {
    # unnecessary fully-qualified name since proto file is using the subpackage name
    type: "sdv.vsidl.test.TirePressure"
  }
}
```

## How to Fix

Remove the unnecessary fully-qualified name in VSIDL file

proto file

```textproto
package: "sdv.vsidl.test"
```

VSIDL FQN Sample 1

```textproto
package: "sdv.vsidl.test"

sdv_service_bundle {
  name: "TireStatusProducer"
  server {
    service: "TireStatus"
  }
}

sdv_service_bundle {
  name: "TireStatusConsumer"
  client {
    service: "TireStatus"
  }
}
```

VSIDL FQN Sample 2

```textproto
package: "sdv.vsidl"

sdv_service_bundle {
  name: "PublishingBundle"
  publisher {
    type: "test.TirePressure"
  }
}

sdv_service_bundle {
  name: "SubscribingBundle"
  subscriber {
    type: "test.TirePressure"
  }
}
```
