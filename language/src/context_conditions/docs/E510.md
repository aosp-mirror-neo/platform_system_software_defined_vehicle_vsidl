# **E510**: Android.bp with recursive filegroup reference

## Description

VSIDLC triggers this error when processing an Android.bp file containing a
`filegroup` target with a reference to another filegroup target in the srcs
list.

## Rationale (Why is this bad?)

Android.bp supports filegroups referring to other filegroups using the ”:name”.
This is not supported by VSIDLC

## Error Example

```textproto
filegroup {
  name: "filegroup_b",
  srcs: ["**/*.proto"],
}
filegroup {
  name: "filegroup_c",
  srcs: [":filegroup_b"],
}
```

## How to Fix

Be sure there are no filegroup references in the srcs of the filegroup required
by VSIDLC. You can replace the group name with its own implementation.

```textproto
filegroup {
  name: "filegroup_b",
  srcs: ["**/*.proto"],
}
filegroup {
  name: "filegroup_c",
  srcs: ["**/*.proto"],
}
```
