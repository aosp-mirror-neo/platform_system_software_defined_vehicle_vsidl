# **E611**: Proto library does not exist for a given proto message

## Description

This error occurs when a Protobuf file defined in the Catalog does not belong to
any library defined in Android.bp .

## Rationale (Why is this bad?)

VSIDLC cannot generate code for Protobuf messages defined in the catalog if
those do not belong to an existing `rust_protobuf` target.

## Error Example

```textproto
// catalog folder
catalog -> vsidl -> a.vsidl
catalog -> protos -> a.proto
// Android.bp not defined
```

## How to Fix

Be sure there is a `rust_protobuf` target containing every proto file defined in
the catalog.

```textproto
// catalog folder
catalog-> Android.bp
catalog -> vsidl -> a.vsidl
catalog -> protos -> a.proto
// Android.bp
rust_protobuf {
  name: "liba_protos",
  crate_name: "a_protos",
  protos: ["protos/a.proto"],
}
```
